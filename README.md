# VR Space Scraper

A physics-driven Virtual Reality environment engineered for the Meta Quest, built with Unity 2022 and the XR Interaction Toolkit (XRIT). 

This project demonstrates core spatial computing mechanics, focusing on rigid-body physics, realistic hand-presence, and optimized standalone VR performance.

## Core Mechanics
* **Physics-Based Interaction:** Engineered using XRIT Socket Interactors and kinematic manipulation to allow users to grab, throw, and interact with objects naturally.
* **Locomotion System:** Lever-controlled spatial navigation combined with continuous movement for immersive traversal.
* **Hand-Presence:** Rigid-body physics applied to player hands, preventing clipping through solid geometry and enhancing realism.

## Technical Optimization
* **Target Hardware:** Meta Quest (Android deployment).
* **Performance:** Optimized rendering pipelines, baked lighting, and texture compression to maintain a strict, stable 60 FPS required for standalone VR comfort without motion sickness.

## Tech Stack
* **Engine:** Unity 2022
* **Language:** C#
* **Framework:** XR Interaction Toolkit (XRIT)
